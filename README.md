## Features

* Donkey death dupe (everything inside the chest of a dying donkey is duped)
* 1.17 anvil dupe
* Lava dupe (hopper with lava above it)
* Minecart portal dupe (chest minecarts entering a nether portal are duped)
* Item frame dupe (chance to dupe when punching the item out of an item frame)
* /dupe command dupe (duplicates the item in your hand)
* /popbob command dupe (similar to /dupe, requires a TNT minecart in the main hand)
* Compatible with Paper 1.21.11+
___

## Commands
* /randomdupes
* /randomdupes reload
* /dupe
* /popbob
___

## Permissions
* randomdupes.main - Allows using /randomdupes and /randomdupes reload (default: op)
* randomdupes.dupe - Allows using /dupe when `needs-permission` is enabled (default: op)
* randomdupes.popbob.dupe - Allows using /popbob when `needs-permission` is enabled (default: op)
